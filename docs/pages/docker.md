# Instalar Docker

La instalación de Docker está integrada en la primera pestaña de la guía:
[Instalación → Preparar el sistema](index.md#1-instalar-las-herramientas-y-docker).

Allí se encuentran las pestañas Ubuntu y Debian, los comandos de Docker, los
permisos del usuario y la configuración de NVIDIA. Seguir la página de
[Instalación](index.md) en orden para preparar todo el entorno.
